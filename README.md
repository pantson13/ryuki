# Ryuki

## GitHub Pages / PWA 测试

这个文件夹已经是可直接发布的 PWA。请把本文件夹内的全部内容放到 GitHub 仓库根目录，必须保留 `assets` 文件夹结构。

1. 在 GitHub 新建仓库，将 `index.html`、`manifest.webmanifest`、`sw.js`、`.nojekyll`、`script.js`、`style.css`、`README.md` 和 `assets` 一起上传。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 中选择 **Deploy from a branch**。
4. Branch 选择 `main`，文件夹选择 `/ (root)`，然后保存。
5. 等待 GitHub 给出 `https://用户名.github.io/仓库名/` 地址后打开测试。

PWA 必须通过 HTTPS 或本机 `localhost` 打开；直接双击 `index.html` 只能看动画，不能注册离线服务。首次联网完整打开一次后，应用资源会缓存，之后可离线启动。

- Android Chrome：浏览器菜单 →“安装应用”或“添加到主屏幕”。
- iPhone Safari：分享按钮 →“添加到主屏幕”。
- 电脑 Chrome / Edge：地址栏右侧的安装图标。

每次上传新版本时，请修改 `sw.js` 顶部的 `CACHE_NAME`（例如从 `v12` 改为 `v13`），否则已安装设备可能继续显示旧资源。

## 手动调整遮挡层

打开页面后，点击右下角的“调整动画”。`ydup.png` 和 `yddown.png` 可以分别调整左右 X、上下 Y；每次点击加减按钮移动 1 个原图像素，也可以直接输入整数。调整结果会自动保存在当前浏览器中。

- X 为正：向右；X 为负：向左。
- Y 为正：向下；Y 为负：向上。
- 已确认的默认位置：`ydup.png` 为 X -20、Y 0；`yddown.png` 为 X -25、Y 0。
- 点击“恢复默认位置”可回到以上参数。

## 新版进场动画

原来的“两圈旋转”已删除。新版动画顺序：

1. 腰带一开始就以图 2 的反向状态和 55% 半透明出现；此时只播放短促水波与蓝—青—绿内部渐变光，不做翻转动作。
2. 水波和渐变光完全消失后，腰带保持 55% 半透明，沿竖直中轴翻转 180° 到图 3 方向。
3. 翻转完全停稳后，半透明才消失，腰带恢复为 100% 不透明。
4. 腰带恢复完全不透明后，整条腰带向设定的最终位置平移。
5. 页面初始显示 `bg2.png`；腰带到达上方后，背景匀速切换为 `bg.png`。
6. 背景切换完成后，`bg3.png` 位于腰带后方，从腰带下方开始由上到下匀速显现。

在调整面板中修改“整段时长（秒）”。数值越大，整段动画越慢；数值越小，动画越快。加减按钮每次调整 0.1 秒，允许范围为 1.5～20 秒，默认时长为 5 秒。修改后会自动保存并立即重新播放。

水波阶段约占整段时长的 20%，默认 5 秒时约为 1 秒。腰带在水波阶段始终保持反向静止，唯一一次 180° 翻转在水波完全消失后开始。

点击腰带或面板中的“重新播放”可随时重播。

## 翻转后的平移位置

调整面板新增“翻转后的最终位置”：

- 最终左右 X：正数向右，负数向左，默认 0。
- 最终上下 Y：负数向上，正数向下，默认 -500。
- 平移时长：默认 1.2 秒，可在 0.2～10 秒之间调整。

X、Y 都按腰带原图像素计算，并会随页面尺寸等比例缩放。调整结果自动保存在当前浏览器中。每次重新播放时，腰带会先回到画面中央；翻转停稳并恢复完全不透明后立即移动到新位置，不会等动画剩余时间结束。

翻转不会被系统或浏览器的“减少动画”设置压缩成瞬间完成。

## 背景与 bg3

- 初始背景：`bg2.png`。
- 腰带平移结束后：用 0.55 秒线性淡变切换至 `bg.png`。
- 背景切换完成后：`bg3.png` 从上向下匀速展开。
- `bg3.png` 默认位于腰带后方，X 为 0、Y 为 160、宽度为 104%、显现时长为 1.5 秒。
- 调整面板中的“bg3 人物出现”可修改 X、Y、宽度和显现时长；参数会自动保存在当前浏览器。
- `bg3` 的 X、Y 以腰带原图像素为单位并随页面等比例缩放；X 正数向右，Y 正数向下。
